# Lab 05 — 栈操作及应用

课程：数据结构与算法（18BJ004）

## 用 Visual Studio 打开

双击：

```
lab05-stack-operations.sln
```

需要 VS2022 +「使用 C++ 的桌面开发」。配置选 `Release | x64`，生成解决方案后将某任务设为启动项目并 F5。

## 任务一览

| 项目 | 说明 |
|------|------|
| `task01-seqstack-basic` | 顺序栈：静态数组实现，初始化、批量入栈、出栈、取栈顶、判空，上溢/下溢判定 |
| `task02-linkstack-basic` | 链栈：头插法入栈、摘链释放出栈、取栈顶、判空，与顺序栈对比 |
| `task03-dec-to-binary` | 综合应用：基于顺序栈的十进制转二进制（除2取余、逆序出栈） |
