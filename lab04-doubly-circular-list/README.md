# Lab 04 — 双向链表与循环链表操作及应用

课程：数据结构与算法（18BJ004）

## 用 Visual Studio 打开

双击：

```
lab04-doubly-circular-list.sln
```

需要 VS2022 +「使用 C++ 的桌面开发」。配置选 `Release | x64`，生成解决方案后将某任务设为启动项目并 F5。

## 任务一览

| 项目 | 说明 |
|------|------|
| `task01-dlink-basic` | 双向链表：初始化、尾插、按位序插入、正向/逆向遍历 |
| `task02-dlink-ops` | 双向链表：按位置/按值查找、删除（双指针联动）、修改 |
| `task03-circular-list` | 单向循环链表 + 双向循环链表：闭环、遍历、增删、对比 |

位序从 **1** 开始。
