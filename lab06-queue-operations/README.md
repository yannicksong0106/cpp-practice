# Lab 06 —— 队列操作及应用

课程：数据结构与算法（18BJ004）

## 用 Visual Studio 打开

双击：

```
lab06-queue-operations.sln
```

需要 VS2022 +「使用 C++ 的桌面开发」工作负载。选择 `Release | x64`，生成解决方案，各程序入口为各任务项目（F5）。

## 任务一览

| 项目 | 说明 |
|------|------|
| `task01-circular-queue` | 循环顺序队列：静态数组实现，初始化、入队、出队、取队头、判空、判满，上溢/下溢判定 |
| `task02-linkqueue-basic` | 链队列：带头结点尾插法入队、删头结点出队、取队头、判空、销毁，与循环队列对比 |
| `task03-dancer-pairing` | 综合应用：基于链队列的舞伴配对，男女两队队头出队配对，输出剩余未配对人员 |
