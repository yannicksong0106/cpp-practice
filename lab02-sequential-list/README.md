# Lab 02 — 顺序表操作

课程：数据结构与算法（18BJ004）

## 用 Visual Studio 打开

双击：

```
lab02-sequential-list.sln
```

需要 VS2022 +「使用 C++ 的桌面开发」。配置选 `Release | x64`，生成解决方案后将某任务设为启动项目并 F5。

## 任务一览

| 项目 | 说明 |
|------|------|
| `task01-basic-seqlist` | 初始化、批量赋值、遍历 |
| `task02-insert-delete-locate` | 按位序插入/删除、按值查找 |
| `task03-menu-application` | 菜单综合：内置 {1,3,5,7,9}，0 退出 |

位序从 **1** 开始。
