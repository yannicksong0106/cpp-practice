# Lab 03 — 链表操作及应用（一）

课程：数据结构与算法（18BJ004）

## 用 Visual Studio 打开

双击：

```
lab03-linked-list.sln
```

需要 VS2022 +「使用 C++ 的桌面开发」。配置选 `Release | x64`，生成解决方案后将某任务设为启动项目并 F5。

## 任务一览

| 项目 | 说明 |
|------|------|
| `task01-basic-linklist` | 带表头单链表：尾插法录入 VR 物体 ID，只读遍历，空链表判断 |
| `task02-multi-field-linklist` | 多字段数据元素：ID/名称/类型/坐标 双层封装，格式化输出 |

全程纯指针操作，不借助数组存储、中转数据。
